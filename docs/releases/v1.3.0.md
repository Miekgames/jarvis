JARVIS v1.3.0: /help.

## Install

Download **JARVIS-v1.3.0-windows.zip** below, unzip it, and double-click **JARVIS.bat**. You need Windows 10 or 11 and Python 3.9 or newer; Node.js isn't needed. Upgrading? Unzip in place of the old folder, keeping your `.env` and `data` folder.

## New: /help

- **In the app:** type **/help** for everything JARVIS can do, area by area, with something to say for each. **/help email**, **/help reminders**, **/help discord**, **/help skills** and so on list everything in one area. "what can you do?" works too.
- **On Discord:** **/help** is a slash command in Discord's own command picker. Only you see the answer, even in a server. Typing /help as a message works as well.
- **Always accurate.** The list is built from what your copy of JARVIS actually has: every line is tied to the tool that does it, and anything switched off in Permissions says which switch turns it on. Your installed skills are listed as their /commands.
