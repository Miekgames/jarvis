JARVIS v1.6.0: projects built by Claude Code, Discord calls that listen, and smarter checklists.

## Install

Download **JARVIS-v1.6.0-windows.zip** below, unzip it, and double-click **JARVIS.bat**. You need Windows 10 or 11 and Python 3.9 or newer; Node.js isn't needed. Upgrading? Unzip in place of the old folder, keeping your `.env` and `data` folder.

## New

- **Projects with Claude Code (optional).** Say "build me a habit tracker app", "make a Discord bot that rolls dice" or "work on my snake game for an hour":
  - If [Claude Code](https://claude.com/claude-code) is installed and signed in to your own account, JARVIS hands the job to it, in a folder of its own under `data/projects`. Questions stay with your usual AI; only asking for something to be made starts a project.
  - Claude Code builds the project and runs its tests. It also looks at the web pages it made, using a throwaway headless Edge or Chrome at desktop and phone size, and fixes what's cut off or broken.
  - The report comes back in the chat and as a notification. With a time given ("for two hours"), it keeps testing and improving until the time is used.
  - It may edit files and run development commands in the project folder. Pushing code, deleting folders and shutting down are refused. "Stop the project" stops it.
  - If Claude Code isn't installed, isn't signed in, or you've hit its usage limit, JARVIS says so, including when the limit resets. The "While away" builder takes the job instead.
  - This needs the new "Hand coding projects to Claude Code" permission, which is off until you turn it on.
- **Projects to Discord, only when you ask.** "Send me the habit tracker on Discord" sends a zip and screenshots to your DMs. "Build me X and send it to my Discord" sends it when it's done.
- **Discord calls now listen.** Talk to JARVIS and pause when you're done: what you say is transcribed on your PC and answered out loud, and what it heard is also sent to your DMs.
  - Only your own voice is listened to.
  - Typing still works too, and "hang up" ends the call.
  - Without speech-to-text installed, JARVIS joins deafened and you type instead.
- **Checklists understand you better.** "Work out" finds "Workout", "chest-press" finds "Chest Press", and near spellings work. If you name a list that doesn't exist but the item is on exactly one list, that item is checked off there. Checklists work in Discord chats and calls too.

## Fixed

- **iPhone zoom.** iPhones no longer zoom into the page when you tap a text box. Pinch-to-zoom still works.
- **JARVIS answering itself.** While JARVIS talks in a Discord call, the PC's wake word ignores its voice, so it no longer answers its own greeting.
- **Emojis.** JARVIS uses an emoji only when it really fits, instead of copying example emojis into replies.
- **"Open …" requests.** A corrupted pattern meant the AI wasn't always offered the open-a-screen tool for "open …" or "close …" requests it had to work out itself. It's repaired.
