# Summarising a document

1. Use `summarise_document` with the file path; if that is not enough, read
   sections with `read_file`.
2. Write:
   - **What it is** -- type, author and date if shown;
   - **The point** -- the main argument or purpose in two or three sentences;
   - **Key points** -- one bullet per section or major idea;
   - **Numbers and dates that matter**;
   - **What it asks of the reader** -- decisions, deadlines, obligations.
3. Keep it to what the document says. Say if parts could not be read.
